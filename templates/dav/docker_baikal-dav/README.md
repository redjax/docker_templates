# Baikal DAV

[Baikal](https://github.com/sabre-io/Baikal) is a calDAV and cardDAV server with a webUI built atop [SabreDAV](https://sabre.io/). This image uses the [`ckulka/baikal` image](https://hub.docker.com/r/ckulka/baikal). It uses the `:nginx` tag by default; you can set `BAIKAL_IMG_TAG` in the [`.env` file](./.env.example) to change the tag.

See all available tags on the [`ckulka/baikal` Docker hub page](https://hub.docker.com/r/ckulka/baikal/tags).
