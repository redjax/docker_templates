# Manage My Damn Life

[Manage My Damn Life](https://intri.in/manage-my-damn-life/) is a frontend for CalDAV. It connects to some DAV backend (i.e. Radicale, Baikal, Davis) and provides a UI for managing calendars and tasks, like a self-hosted Google Calendar.

## Setup

- Copy [example `.env`](./.env.example) to `.env`
- Run [`generate-secrets.sh` script](./generate-secrets.sh)
  - Copy the generated environment variables in the `.env` file
- Edit the `.env` file
  - Ensure `MMDL_IMG_TAG` is on a [recent, supported version](https://github.com/intri-in/manage-my-damn-life-nextjs/releases)
  - Set `MMDL_BASE_URL`. Examples:
    - `http://192.168.1.111:3000`
    - `https://mmdl.mydomain.com`
  - Ensure the secrets generated by `generate-secrets.sh` are pasted into the appropriate variables
  - Choose a [database overlay](./overlays/) and set `DB_DIALECT`
    - If using an external database, set the correct dialect here
- If using SQLite, ensure Alpine tag is [a recent version](https://hub.docker.com/_/alpine/tags)
- If using MySQL, ensure MySQL tag is [a recent version](https://hub.docker.com/_/mysql)
- If using Postgres, ensure Postgres tag is [a recent version](https://hub.docker.com/_/postgres)

## Usage

After completing [setup](#setup), run a `docker compose` command, depending on which database you chose:

- Local SQLite: `docker compose -f compose.yml -f overlays/sqlite.yml up -d`
- Local MySQL: `docker compose -f compose.yml -f overlays/mysql.yml up -d`
- Local Postgres: ``docker compose -f compose.yml -f overlays/postgres.yml up -d`
- Remote database: `docker compose up -d`

### First Run

After bringing the container up, navigate to your `MMDL_BASE_URL` address. You should see a red bar along the top telling you to initialize the database; click it and follow the prompts until you get to the page with a "create user" button. Click that button and create your admin user.

You should also create a non-admin user to authenticate as for regular usage. Add a DAV account by clicking the settings cog and "Manage CalDAV Accounts."
